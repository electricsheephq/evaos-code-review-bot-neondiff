# v1.0.5

NeonDiff 1.0.5 is the next immutable CLI/package candidate. This source
candidate is not a publication claim: npm publication, the matching GitHub
Release, and the typed registry proof must be recorded before installation or
release-readiness claims are made.

## Changes

- Derive sealed-worker and Desktop bundle version checks from `package.json`.
- Make the public config schema default to explicit mandatory API-backed
  activation with `requires-license` or `disabled`, while accepting the
  historical v1.0.4 compatibility label without granting free review.
- Add a strict `neondiff.npm-publication-proof.v1` gate binding package bytes,
  tag, source identity, workflow run, registry latest, and predecessor.
- Add a protected-main-only, serialized predecessor rollback mode that can move
  `latest` from immutable 1.0.5 to immutable 1.0.4 only after both package
  identities and provenance are verified.

## Proof boundary

This file proves source-candidate intent only. It does not prove that
`neondiff@1.0.5` is published, that npm `latest` points to 1.0.5, that a
GitHub Release exists, or that a signed/notarized Desktop artifact is ready.
Those claims require the publication proof at
`docs/evidence/v1.0.5-publication-proof.json` and the corresponding registry
and release readback.
