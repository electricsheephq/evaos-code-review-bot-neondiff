# NeonDiff 1.1.1

## Version

`1.1.1` / `v1.1.1`. Publication is pending until the release workflow succeeds.

## Release path (lean)

Follow the [lean release checklist](../release-governance.md#lean-release-path-110-and-later).
`release-npm.yml` requires exact-tag CI, publishes with provenance, verifies
signatures and attestation, and confirms the npm shasum and `latest` channel.

## Install

After publication and channel verification: `npm install -g neondiff@1.1.1`.

## Rollback

An owner runs `npm dist-tag add neondiff@1.1.0 latest`, then verifies
`npm view neondiff dist-tags.latest --prefer-online`.

## Product changes

### Fixed
- **`review-pr --ci` no longer fails the job on a normal skip.** A pull request NeonDiff deliberately skips now exits 0 with a GitHub Actions notice on stderr: a draft (including `/neondiff review` on a draft), a head that moved before the job started, a closed or already-processed head, or a base-merge-only push. An outside contributor's pull request where restricted review can't be guaranteed also exits 0, with a warning instead. A license-gate skip on a private repository, a failed review, and any unknown outcome still exit 1. Non-CI commands are unchanged. The JSON report now includes the scoped pull request's status. (#1218)
- The Node/Foundation secret-rule differential test has a 240 s budget for a cold Swift compile on hosted runners. (#1217)

### Docs
- The CI runner guide installs `neondiff@1.1.1` and pins `electricsheephq/neondiff-action` v1.0.1, which runs 1.1.1. The Action's floating `v1` tag moves to v1.0.1 once 1.1.1 is on npm.
- The CI runner guide points to the `electricsheephq/neondiff-action` GitHub Action, pinned to its release commit. Its workflow skips draft pull requests, and it scopes licenses per plan: Team for an organization, Solo for one developer's own account. (#1219)
- `review-local` skips the license activation check, but it is not a license grant. Reviewing private or internal code with it outside evaluation needs a paid license under LICENSE.md. (#1219)
