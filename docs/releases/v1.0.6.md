# v1.0.6

NeonDiff 1.0.6 is a small CLI/package release on top of 1.0.5. It ships the
fixes already merged to `main`; no new review behaviour is switched on by
default.

## Changes

- Publish original LCM-X review verdicts without numeric scores (#1158).
- `neondiff init` gives configs outside protected source/package roots their
  own runtime, state, evidence and license paths beside the config, instead of
  the packaged worker's `/tmp/neondiff` placeholders.
- Configured review concurrency is real: each daemon cycle settles one bounded
  parallel PR batch, and issue enrichment runs independently.
- Release plumbing: npm cleanup lag fails closed (#1155), npm source identity is
  preserved (#1160), and the serialized predecessor rollback targets the exact
  `1.0.6 -> 1.0.5` pair.

## Install

```bash
npm install -g neondiff@1.0.6
```

## Rollback

Move npm `latest` back to `1.0.5` with the protected predecessor-rollback mode
of `publish-npm.yml`, or install the previous version directly:
`npm install -g neondiff@1.0.5`.

## Proof boundary

This file states release intent. Publication is proven only by the npm registry
readback (`npm view neondiff dist-tags`), npm provenance, and the matching
GitHub Release.
